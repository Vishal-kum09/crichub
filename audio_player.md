# Live Audio Pipeline: Frontend Integration Guide

This document outlines everything you need to connect to the live match audio streams generated by the backend pipeline.

## Overview

The audio pipeline mixes live commentary over a continuous ambient stadium crowd noise in real-time. It outputs an **HLS (HTTP Live Streaming)** feed for each active match. 

## Connection Details

> [!IMPORTANT]
> The backend generates unique, isolated streams per match. Make sure you dynamically insert the correct `match_id` into the URL.

- **Base URL:** `https://live-audio-pipeline-106171733624.europe-west2.run.app`
- **Stream Format:** HLS (`.m3u8` playlist with `.ts` audio segments)
- **Endpoint Structure:** `/{match_id}/stream.m3u8`

**Example:**
If the user is watching Match ID `match_1001`, point your audio player to:
`https://live-audio-pipeline-106171733624.europe-west2.run.app/match_1001/stream.m3u8`

## CORS Configuration

> [!TIP]
> **CORS is fully enabled on the backend.** 
> You do **not** need to set up any middleware proxies or configure your own CORS headers. The API accepts requests from any origin (`*`).

## Stream Characteristics & Limitations

- **Rolling Window:** To conserve server memory, the HLS stream maintains a rolling 30-second window. Older audio segments are automatically deleted.
- **Latency:** Because this is an HLS stream, you should expect roughly 10-15 seconds of latency from real-time. This is normal and expected.
- **Audio Format:** The stream outputs an audio-only feed (AAC codec, 192kbps).
- **Idle Timeout:** If a match receives no new commentary deliveries for 30 minutes, the backend will shut down that specific match's pipeline to save resources, and the `.m3u8` file will eventually 404.

## Recommended Web Players

If you are building for the web, standard HTML5 `<audio>` tags do not natively support HLS in all browsers (e.g., Chrome). We recommend using one of the following libraries:

1. **[HLS.js](https://github.com/video-dev/hls.js/)** (Recommended) - Lightweight and works perfectly with audio-only feeds.
2. **[Video.js](https://videojs.com/)** - A heavier, full-featured player if you need extensive UI controls.

### Minimal Example (HLS.js)

```javascript
import Hls from 'hls.js';

const audio = document.getElementById('match-audio-player');
const matchId = 'match_1001';
const streamUrl = `https://live-audio-pipeline-106171733624.europe-west2.run.app/${matchId}/stream.m3u8`;

if (Hls.isSupported()) {
  const hls = new Hls();
  hls.loadSource(streamUrl);
  hls.attachMedia(audio);
  hls.on(Hls.Events.MANIFEST_PARSED, function() {
    audio.play();
  });
} else if (audio.canPlayType('application/vnd.apple.mpegurl')) {
  // Safari native support
  audio.src = streamUrl;
  audio.addEventListener('loadedmetadata', function() {
    audio.play();
  });
}
```
